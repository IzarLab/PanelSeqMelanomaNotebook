# Analysis notebooks

This folder contains the figure notebooks and the minimal PyClone-VI wrapper used for Figure 4B.

Files:

- `figure_1_scripts.ipynb`
- `figure_2_scripts.ipynb`
- `figure_3_scripts.ipynb`
- `figure_4_scripts.ipynb`
- `cox_analysis_scripts.ipynb`
- `run_pyclone_vi.sh`

Shared assumptions:

- all notebooks use one external preformatted clinical metadata file
- non-clinical staged inputs come from the scripts in the main repository
- the notebooks are meant to regenerate plots from staged inputs, not to perform heavy raw-data cleanup
